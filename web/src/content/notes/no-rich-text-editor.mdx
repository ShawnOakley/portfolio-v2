# No rich-text editor

You paste plain text or drop a PDF. There is no rich-text editor on the page,
and I left it out on purpose.

The checker reads a string, and every highlight it returns is a pair of
offsets into that string. Quill, Tiptap, and Lexical each keep a document
model of their own, so I would have been translating offsets on every
keystroke to keep the highlights lined up. With plain text, the page and the
engine count characters the same way.

The cost is that you can't bold or indent a brief here. The check never read
formatting anyway.
