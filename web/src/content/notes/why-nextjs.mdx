# Why Next.js

When you press Check, your browser sends the brief to this site, and the
site's server calls the checker. The browser never talks to the checker or to
the model host, and it never holds a key.

That is why the page uses a Next.js server action and not a script that calls
the API directly. Calling the checker from the browser would have meant
opening it to other origins. Calling the model from the page would have meant
shipping a key to every visitor.
