# Why Next.js

**Decision.** The checker page calls the API from a Next.js server action. The
browser never calls the model host and never holds a key.

**Why.** The page posts the brief to this site, and the server calls the
checker. The browser does not need the checker to allow its origin.

**What I rejected.**

- _Calling the checker from the browser._
- _Calling OpenRouter from the page._
